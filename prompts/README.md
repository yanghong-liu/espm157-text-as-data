# Conversation records

These files are English translations of exported assignment conversation snapshots. Student and
Assistant roles, message order, scope choices, judgments, and corrections are preserved. Product
names are normalized to Assistant; interface wrappers and repeated question payloads are omitted.
Original-language snapshots are retained separately. Historical counts show changes during the
analysis; the final corpus has 303 rules. Repeated delivery of the butterfly answer is one judgment.
